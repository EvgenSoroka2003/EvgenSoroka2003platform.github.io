# Рентабельність операційної діяльності промислових підприємств

Інтерактивна платформа для розрахунку індикатора виробничої безпеки (методична база: наказ Мінекономрозвитку № 1277 від 29.10.2013, втратив чинність у 2025 р.).

## Файли
- `index.html` — розмітка сторінки
- `style.css` — стилі
- `script.js` — розрахунки, перевірка даних, висновок. Формула (`calcROD`) і пороги (`THRESHOLDS`) — на початку файлу

## Публікація на GitHub Pages
1. Завантажте всі файли в корінь репозиторію.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. Сайт: `https://<логін>.github.io/<репозиторій>/`

## Важливо
Формулу та порогові значення звірте з таблицею індикаторів у наказі № 1277.

Джерело (APA): Міністерство економічного розвитку і торгівлі України. (2013). *Про затвердження Методичних рекомендацій щодо розрахунку рівня економічної безпеки України*: Наказ від 29 жовтня 2013 р. № 1277. Верховна Рада України. https://zakon.rada.gov.ua/rada/show/v1277731-13#Text
